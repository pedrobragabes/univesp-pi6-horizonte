# Política de segurança

## Escopo suportado

A branch `main` recebe correções de segurança. Protótipos, dados fictícios e
configurações locais deste projeto não constituem um serviço de produção.

## Como relatar

Não abra uma issue pública com credenciais, dados pessoais ou instruções de
exploração. Use **Security > Advisories > Report a vulnerability** no
repositório. Se esse recurso não estiver disponível, contate o proprietário
pelo perfil do GitHub antes de divulgar detalhes.

Inclua, quando possível:

- componente e versão afetados;
- passos mínimos para reprodução;
- impacto observado;
- sugestão de mitigação;
- confirmação de que nenhum dado real foi exposto.

## Limites

Não execute testes contra sistemas de terceiros, ambientes acadêmicos,
dispositivos ou dados reais sem autorização. Evidências extensionistas e dados
de parceiros devem seguir consentimento, minimização e regras da UNIVESP.
